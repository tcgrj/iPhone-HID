## 常见问题

**看不到 TechGe iPhone Screen**：确认 AirPlay 终端没有报错，Mac/iPhone 在同一 LAN，路由器未隔离客户端，GStreamer 元件齐全。此名称由 Mac 广播，开发板单独供电不会出现接收器。

**没有画面但蓝牙正常**：手动重新选择 iPhone 控制中心的屏幕镜像。网页保留的旧画面不能作为下一次点击依据，控制器会等新帧或停止。

**不能配网/找不到串口**：使用支持数据的 USB 线、正确 USB 端口，并确认固件的 USB CDC 设置。不要通过未知串口盲目刷写。

**Wi-Fi 正常但不能点击**：检查辅助触控是否打开、TechGe Wireless iPhone 是否配对。固件收到指令不等于 iPhone 已处理，仍要看实际画面。

**Codex 不存在或模型请求失败**：运行 doctor，设置 PATH 或 CODEX_BIN，在正常 CLI 中确认登录与模型权限。协议出错时停止，不通过去掉工具隔离来强行兼容。

**某个按钮总点不准**：iOS 指针可能从圆点变成高亮按钮。先停止任务并检查坐标、悬停和投屏缩放，不能把预测位置当作已验证位置。

**中文不能直接输入**：当前 HID 输入限制为 ASCII，可输入拼音后选择候选。不要声称支持任意 Unicode 键入。

**Siri 收到但无操作**：检查 Mac 的网关 IP、手机 LAN 权限、蓝牙和投屏；查看网页任务状态。提交成功只是入队，不是任务成功。不要重复提交购物任务。

**端口已占用**：可能已有控制台/接收端。先确认所有现有任务和服务，不要直接杀掉不明进程。默认端口：网页 8766、内存 MJPEG 8767、ESP32 命令 8768、可选 Siri 8769，UxPlay 基础端口 7110。
